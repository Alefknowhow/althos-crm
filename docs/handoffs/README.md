# Handoffs — arquivo histórico

`.ai/HANDOFF.md` é o handoff **atual** (sempre sobrescrito). Quando uma
tarefa relevante é concluída e vale preservar o handoff final como registro
histórico (ex.: feature grande, decisão que vale consultar depois), copie o
conteúdo de `.ai/HANDOFF.md` pra cá antes de começar a próxima tarefa:

```
docs/handoffs/YYYY-MM-DD-<slug-da-tarefa>.md
```

Isso é opcional e manual — não é sobrescrito nem gerado automaticamente.
Use para tarefas grandes o suficiente pra render `.harness/tasks/completed/`;
para o dia a dia, o handoff vivo em `.ai/HANDOFF.md` já é suficiente.
